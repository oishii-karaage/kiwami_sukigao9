# 好き顔9選

GitHub Pagesで動く「好き顔9選」サイトです。

## 使い方

- `index.html`：参加者側のゲーム画面
- `app.js`：ゲーム処理
- `admin.html`：候補者100人の名前・写真を登録する管理画面

公開URLの末尾に `/admin.html` を付けると管理画面を開けます。

### 管理画面について

管理画面で登録した候補者データは、現在はブラウザのローカル保存領域に保存されます。
そのため、同じiPhone・同じブラウザで開く限り反映されますが、別の端末や別ブラウザには自動同期されません。

100人分の写真を登録した後、必要なら「データを書き出す」でJSONとして保存できます。

## 注意

この版は、候補者管理を簡単にするためのローカル管理方式です。
複数端末・複数ユーザーで同じ候補者データを共有する管理機能が必要になった場合は、別途データベース等を接続する必要があります。

## 表示名
管理画面では「コンビ名」と「個人名」を別々に登録できます。コンビ名は小さく、個人名は大きく表示されます。


## 予選グループ機能
管理画面で、100人を写真を見ながら4人ずつ25組に手動で分けられます。
「予選組」のプルダウンで各候補者を第1〜25組へ移動し、「予選グループを保存」を押します。
保存後は好き顔9選の予選で、その組み合わせが使われます。


## 本戦のテスト版仕様
予選後も100人全員が本戦に参加します。
本戦は総当たりではなく、各候補者が約8回ずつ比較されるように対戦カードを作ります。
同じ組み合わせは重複させず、比較回数が少ない候補者を優先して組み合わせます。
