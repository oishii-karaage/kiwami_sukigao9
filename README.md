# 好き顔9選

スマホ向けの好き顔9選サイトの試作です。

## 現在の仕様
- 候補者100人
- 4人ずつ予選表示
- 1組につき最大3人選択
- 最大75人が本戦へ
- 本戦は二択＋引き分け
- 写真タップで選択
- 戻るボタンあり
- Elo方式で集計
- 上位9人を3×3表示
- 全順位も表示

## 候補者の差し替え
`app.js` の `candidates` 配列を編集してください。

例:
```js
const candidates = [
  { id:1, name:"○○", image:"images/01.jpg" },
  { id:2, name:"△△", image:"images/02.jpg" },
];
```

画像は `images` フォルダに入れてください。
